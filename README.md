# 📊 Smart Student Productivity Analyzer

A beginner-friendly Data Science and Machine Learning project that analyzes student lifestyle and academic habits to estimate their productivity level and identify possible routine imbalance.

## 🚀 Project Overview

Students have different study patterns, sleep schedules, phone usage, exercise habits, attendance, and assignment performance.

This project analyzes these factors and predicts a student's **Productivity Level** as:

- 🟢 High
- 🟡 Medium
- 🔴 Low

It also provides a **Routine Imbalance Indicator** based on simple rule-based conditions related to study hours, sleep, phone usage, and exercise.

> **Note:** The Routine Imbalance Indicator is a project feature and is not a medical diagnosis.

## 🎯 Objectives

- Analyze student daily habits and academic performance
- Clean and prepare the dataset
- Perform Exploratory Data Analysis (EDA)
- Visualize relationships between different factors
- Build a Machine Learning classification model
- Predict productivity level for a new student
- Create a simple Streamlit interface

## 📂 Dataset

The dataset contains **50 manually created/simulated student records**.

### Features

| Feature | Description |
|---|---|
| Study_Hours | Daily study hours |
| Sleep_Hours | Daily sleep hours |
| Phone_Hours | Daily phone usage |
| Exercise_Minutes | Daily exercise duration |
| Attendance | Attendance percentage |
| Assignment_Score | Assignment score |

The dataset is **not collected from real students**. It was manually created for learning and project demonstration purposes.
